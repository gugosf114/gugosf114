# George Abrahamyants

I have no programming background. JD, ten years in contracts, compliance, and state tax.

Fifteen months ago code looked like sheet music to me. Since then I've shipped an Android app and a desktop engine for voice reconstruction (35-claim U.S. provisional patent, sole inventor), an agentic marketing platform that runs a real bakery, a tamper-evident audit-defense platform, and a diagnostic tool that measures AI drift — all built by orchestrating AI, all in production.

I started using AI for real work and noticed it kept failing in ways that weren't my fault — confident outputs that didn't survive verification, drift that got worse with clearer instructions, apology loops that repeated the same error. So I documented the patterns, tested what actually fixes them, and built tools that measure them.
